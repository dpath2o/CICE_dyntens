### Create, build and submit

```bash
(
set -euo pipefail
cd /g/data/gv90/da1339/src/CICE_dyntens
git pull --ff-only origin dev
load_modules

runs=/g/data/gv90/da1339/cice-dirs/runs
restart="$runs/dyntens01/input_restart/iced.2000-09-01-00000.nc"
# If the preserved input restart is elsewhere, change only the line above.
python CICE_testing/scripts/g0_global_workflow.py prepare     --repo "$PWD" --runs "$runs" --restart "$restart"

(cd global_tests/G0/dt_g0_off; ./cice.build)
[[ -x "$runs/dt_g0_off/cice" ]]
cp -p "$runs/dt_g0_off/cice" "$runs/dt_g0_unity/cice"
sha256sum "$runs/dt_g0_off/cice" "$runs/dt_g0_unity/cice"

for name in dt_g0_off dt_g0_unity; do
    (cd "global_tests/G0/$name"; qsub ./cice.run | tee g0-job-id.txt)
done
)
```

Check `qstat -u da1339`. Analyse after both jobs have finished.

The checker requires successful MPI exits and model completion, unchanged prepared inputs, identical executable/input hashes, global output dimensions, three histories and two daily restarts, correct restart dates/steps, and exact decoded equality of every output variable, including masks and finite unmasked values. This includes the physical and thermodynamic fields written by the inherited namelist; it does not independently close mass/energy budgets or compare against a pre-development executable.

The G0 comparison does not require the inherited FSD sums to match the strict box tolerance. Equal FSD numerical departures are recorded by output equality and assessed in G1; differing physical output still fails. No model FSD checks are disabled: candidate diagnostics are off in both runs, and the enabled run uses the prescribed constant $g=1$ mode.

Output: `g0-short-validation.json`, `g0-short-analysis.txt` and the Bash transcript. A PASS is for this short off/unity comparison only. Retain PBS output/accounting with the model logs before extending the test.
