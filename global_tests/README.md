G0–G2 are separate from the box programme. The inherited `dyntens01` template belongs to G0, but its presence is not acceptance of the new global forcing/unity gate. Planned global configurations must retain active baseline thermodynamics, forcing and wave/FSD provenance. `box_fsd` is currently guarded to the controlled box; no global feedback run is enabled by reorganising files.
